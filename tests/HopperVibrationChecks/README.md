# 料仓振动检查

运行 `dotnet run --project tests/HopperVibrationChecks/HopperVibrationChecks.csproj`。

检查只连接本机随机端口的 TCP 模拟控制器，不加载主窗口、不连接运动卡或实际振动设备。覆盖料仓指令字段顺序与补零、定时时长、手动停止、排队启动取消、动作互斥、生产互锁、断开前停止、退出前停止、参数保存和旧配置兼容。测试输出目录会生成连接配置页截图。

料仓启动按厂家协议使用 `&13,xx,yyy$`（两位振幅、三位频率）；`&04$` 同时停止振动盘和料仓。测试验证发送的数据和软件行为，设备实际响应仍需现场确认。
