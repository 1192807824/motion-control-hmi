◆ SetRenderInterval()

void SetRenderInterval ( int  pMillseconds)

设置渲染间隔(ms)

参数
pMillseconds渲染间隔

备注

            用于减低渲染频率。设置后，执行结束触发渲染时先校验距离上一次渲染的时间是否已超过设置的间隔时间，已超过则正常渲染，未超过则跳过此次渲染
